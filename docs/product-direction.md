# Product direction

## Core promise
A review-first moderation helper for ordinary WeChat groups.

## What makes it useful
- no direct auto-kick by default
- desktop GUI for quick human review
- audit trail
- eventually simple Windows install flow

## Real target users
- owners/admins of ordinary WeChat groups
- student groups
- marketplace/community groups with ad spam problems

## Short-term product goal
Get from mock/demo state to a working desktop-assisted moderation workflow on Windows.
