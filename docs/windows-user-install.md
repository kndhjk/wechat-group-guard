# Windows user install

## Fastest path

1. Install Python 3
2. Download this repo or release zip
3. Double-click:
   - `scripts\\install.bat`
4. After install, double-click:
   - `scripts\\run_gui.bat`

## Remove

Double-click:
- `scripts\\uninstall.bat`

## Future packaging
Later this project can be distributed as a built EXE package to avoid requiring Python on end-user machines.
